# Privacy Policy – NEPass

**Last updated:** 28 March 2026

## 1. Introduction

NEPass is a private authentication and identity service operated by **Phenix Hartogh**. It provides centralised authentication and account management for authorised users to access various private services and applications.

This Privacy Policy explains how NEPass collects, uses, stores, and protects personal information when users access or interact with the service.

NEPass is hosted on infrastructure provided by **Linode LLC** in **Sydney, New South Wales, Australia**.

The service is primarily used by individuals located in **Victoria, Australia** and access is granted strictly on an **invite-only basis**.

By using NEPass, you acknowledge and agree to the collection and handling of your information as described in this Privacy Policy.

## 3. Information We Collect

NEPass collects information necessary to provide secure authentication services.

### 3.1 Account Information

When an account is created or managed within NEPass, we may collect:

* Email address
* Username
* Password (stored in encrypted/hashed form)
* IP address
* User agent and device information
* Account identifiers
* Authentication credentials for supported login methods

### 3.2 Authentication and Security Logs

To maintain security and integrity of the service, NEPass records authentication-related data including:

* Login timestamps
* IP addresses used during authentication
* Device and browser information
* Failed login attempts
* Two-factor authentication usage
* Audit logs relating to account activity
* Access logs

These logs assist in detecting unauthorised access, maintaining system security, and auditing authentication events.

---

## 4. Social Login Providers

NEPass supports authentication through third-party identity providers including:

* Apple
* Discord
* Facebook
* GitHub
* Google
* Telegram
* Twitter (X)

When a user authenticates using one of these providers, NEPass may receive information from that provider, such as:

* Email address
* Account identifier provided by the provider
* Username or display name

NEPass stores the **provider account identifier and associated email address** in order to link the external identity to the user's NEPass account.

Profile pictures and other optional social profile data are **not stored** by NEPass.

Users may link **multiple providers** to a single NEPass account, however only **one account per provider** may be linked.

Use of these providers is subject to the privacy policies of the respective providers.

---

## 5. Two-Factor Authentication

To improve security, NEPass requires two-factor authentication (2FA).

Supported authentication methods include:

* Time-based One-Time Passwords (TOTP)
* WebAuthn / passkey authentication
* Static recovery keys

Information necessary for these authentication methods is securely stored to enable verification.

---

## 6. Cookies

NEPass uses cookies required for authentication and session management.

These include:

**Session Cookies**

* Used to maintain an authenticated session during login.

**Remember Me Cookies**

* Allow users to remain logged in between sessions when selected.

NEPass does **not use tracking or advertising cookies**.

---

## 7. How Information Is Used

Information collected by NEPass is used to:

* Authenticate users
* Provide secure login access to connected services
* Maintain audit logs and security records
* Detect suspicious or unauthorised access
* Manage linked identity providers
* Support system administration and troubleshooting

---

## 8. Sharing of Information

NEPass does **not sell or distribute personal information**.

Limited information may be shared with services that use NEPass for authentication.

When a user signs in to an external application using NEPass, the following information may be shared with that application:

* Email address
* Account identifier
* Authentication confirmation

These services may include, but are not limited to:

* Family-hosted infrastructure
* Websites
* Home automation services
* Internal applications
* Email services
* Cloud services

Each connected service is responsible for its own handling of personal data once authentication has occurred.

---

## 9. Data Storage and Infrastructure

NEPass is hosted on servers located in **Sydney, Australia**, provided by **Linode LLC**.

Data is stored using secure server infrastructure and protected using industry-standard technologies including:

* HTTPS encryption
* Firewall protection
* Restricted administrative access
* Mandatory two-factor authentication for user accounts

Administrative access to the system is strictly limited.

---

## 10. Data Retention

NEPass retains data for operational and security purposes.

### Account Data

Account information is retained **indefinitely**, including after account deactivation, in accordance with agreements between the service operator and users.

### Logs

Authentication and audit logs are retained **indefinitely** for security monitoring and system auditing.

### Backups

System backups are performed **daily** and retained for **365 days**.

Backups older than **365 days** are automatically deleted.

* Mandatory two-factor authentication
* Restricted administrative access
* Authentication logging and monitoring

While reasonable steps are taken to protect information, no online system can guarantee absolute security.
